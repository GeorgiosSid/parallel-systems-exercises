# Parallel Systems Exercises

This repository contains my programming assignments for the course **Parallel Systems and Programming (MYE023)** at the University of Ioannina, 2023–2024.

## Overview
The exercises explore parallel and distributed programming using OpenMP, CUDA, OpenMP Offloading, and MPI.  
Each project includes code implementations, performance measurements, and analysis reports.

## Contents
- **Homework 1 (OpenMP)**:
  - Parallel prime number finding.
  - Image blurring with loop and task parallelism.
  - Task dependencies in OpenMP 4.0.

- **Homework 2 (GPU Programming)**:
  - CUDA device information tool (`cuinfo`).
  - Image blurring using GPU offloading with OpenMP directives.

- **Homework 3 (MPI & Hybrid Programming)**:
  - Parallel image blurring using MPI.
  - Matrix multiplication with MPI + OpenMP hybrid model.
  - Study and guide for one-sided communications (MPI RMA).

## Technologies
- C / C++ Programming
- OpenMP (parallel CPU programming)
- CUDA (GPU programming)
- MPI (Message Passing Interface)

## Features
- Parallel and distributed computation techniques.
- Comparison of serial vs parallel performance.
- Hands-on experiments with thread/task-level parallelism, GPU acceleration, and cluster computing.
